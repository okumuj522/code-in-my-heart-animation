# Code in My Heart

A full-screen, 60-second Python animation about Ocholla James. It shows the exact profile words Kisii University, Computer Science Student, and Python Programmer while a flower blooms, code appears, and an original coding-themed instrumental plays.

## Run on Windows

Open Command Prompt in this folder and run:

```text
python main.py
```

No packages need to be installed. The animation and original music use Python's built-in libraries. The music file is created automatically on first run.

## Controls

- Space: pause or continue
- R: restart the film
- M: mute or restore music
- Esc: exit

The full animation and music run for 60 seconds.
